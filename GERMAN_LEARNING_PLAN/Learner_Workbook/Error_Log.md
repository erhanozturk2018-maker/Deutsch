# Error Log

Most learners make the same 10–20 mistakes over and over. This log finds **yours**, so you can fix them on purpose instead of hoping they disappear. Every cumulative review in the course has an "error clinic" built from this file.

**When to write in it:**
- after every rated speaking or writing task
- after an AI or tutor correction
- after a unit quiz

**What to write:** only the 1–3 **most important** mistakes each time: the ones that repeat, or that cause misunderstanding. Not every typo.

**Codes** (the same as in the [Rubrics](../Resources/Rubrics.md#error-categories)):

| Code | Category | Code | Category |
|---|---|---|---|
| WO | word order | PR | preposition |
| VF | verb form | WC | word choice / collocation |
| CA | case | SP | spelling / capitalisation |
| GE | gender / article | PU | punctuation |
| AE | adjective ending | RE | register (*du/Sie*, tone) |
| | | PRN | pronunciation |
