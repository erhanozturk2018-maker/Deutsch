# B2-U02 — Arbeitswelt & Karriere · Überblick & Wortschatz

> **Niveau:** B2.1 · **Einheit 2 von 12** · **4 Lektionen, ungefähr 6 Stunden** · **Load:** ●●● hoch
> **Vorher:** [B2-U01 Identität & Gesellschaft](../B2-U01_Identitaet_und_Gesellschaft/00_Overview_und_Wortschatz.md)
> **Was diese Einheit Ihnen gibt:** die Sprache des Berufslebens auf zwei Ebenen — die **schriftliche** (Funktionsverbgefüge, Nominalstil, Protokoll, E-Mail) und die **mündliche** (Kritik äußern, ohne den Konflikt zu vergrößern). Beides zusammen entscheidet im Beruf mehr als Wortschatzumfang.

## 🎯 Ziele

Am Ende dieser Einheit können Sie:
- **Funktionsverbgefüge** verwenden: *eine Entscheidung **treffen** · Einspruch **erheben** · in Kraft **treten** · zur Verfügung **stellen***
- zwischen **Nominalstil** und **Verbalstil** wechseln, in beide Richtungen: *Nachdem die Unterlagen geprüft worden waren* ↔ *Nach Prüfung der Unterlagen*
- **Kritik in fünf Schritten** äußern und Beobachtung von Bewertung trennen
- die **Eskalationsleiter** benutzen, ohne Stufen zu überspringen
- ein **Protokoll**, eine **Absprache-E-Mail** und eine **Eskalations-E-Mail** schreiben

## Grammatik im Überblick

**Funktionsverbgefüge — Nomen trägt die Bedeutung, Verb trägt die Grammatik**

| Funktionsverb | Beispiele |
|---|---|
| **treffen** | eine Entscheidung / eine Vereinbarung / Vorbereitungen treffen |
| **stellen** | eine Frage / einen Antrag stellen · in Frage / zur Verfügung stellen |
| **nehmen** | Rücksicht / Einfluss nehmen · zur Kenntnis nehmen · Abstand nehmen von |
| **üben** | Kritik / Druck / Verzicht üben |
| **erheben** | Anspruch / Einspruch / Vorwürfe erheben |
| **halten** | eine Rede / Rücksprache / eine Frist halten |
| **ergreifen** | Maßnahmen / die Initiative / das Wort ergreifen |
| **geraten in** | in Verzug / in Schwierigkeiten geraten |
| **treten in** | in Kraft / in Verhandlungen / in Kontakt treten |
| **ziehen** | in Betracht / in Erwägung ziehen · Schlüsse ziehen |
| **bringen** | zum Ausdruck / zur Sprache bringen |
| **leisten** | Widerstand / Hilfe / einen Beitrag leisten |

> Artikel und Präposition sind **fest**: *in Kraft* (ohne Artikel), *zur Verfügung*, *in Betracht*, *außer Acht*, *unter Druck*. Verstärkt wird mit einem **Adverb**, nicht mit einem Adjektiv: *scharf Kritik üben*.

**Nominalstil ↔ Verbalstil**

| Konjunktion | wird zu | Beispiel |
|---|---|---|
| nachdem | **nach** + D | nach Prüfung der Unterlagen |
| bevor | **vor** + D | vor Beginn des Projekts |
| weil | **aufgrund / infolge / wegen** + G | aufgrund der gestiegenen Kosten |
| obwohl | **trotz / ungeachtet** + G | trotz mehrfacher Erinnerung |
| wenn, falls | **bei** + D | bei Rückfragen · bei Bedarf |
| damit, um zu | **zur / zwecks** + G | zur Senkung der Kosten |
| indem | **durch** + A | durch Vereinfachung der Abläufe |
| während | **während** + G | während der Verhandlungen |

> **Regel:** höchstens **eine** Nominalkonstruktion pro Satz. Ketten aus Nominalisierung + Genitiv + Genitiv heißen auf Deutsch **Substantivitis** und gelten auf B2 als Stilfehler.

**Kritik in fünf Schritten**

Rahmen setzen → **Beobachtung** (überprüfbar, mit Datum) → **Wirkung auf mich** → **offene Frage** → **Vereinbarung mit Frist**.
Die **Eskalationsleiter**: Hinweis → Gespräch → Absprache → **schriftliche Bestätigung** → Leitung einbeziehen → förmliche Beschwerde.

Tabellen: [Grammar Tables → Funktionsverbgefüge und Nominalstil](../../Resources/Grammar_Tables.md#b2-funktionsverbgefüge-and-nominal-style) · [Redemittel → Konflikt und Kritik](../../Resources/Redemittel.md#b2-criticism-conflict-and-escalation)

## Hauptaufgabe

**Gespräch und Protokoll** (L4, Aktivität 2): Eine Nachbarabteilung liefert seit zwei Monaten zu spät, ein freundliches Gespräch blieb wirkungslos. Sie führen das zweite Gespräch — **in beiden Rollen** — und halten das Ergebnis in einer E-Mail von höchstens acht Zeilen fest, mit Handlung, Zuständigkeit, Frist und Überprüfungstermin. Dazu: die **Besprechung und ihr Protokoll** (L1), die **Übersetzung eines Bescheids** (L2), das **Gespräch, das Sie vermeiden** (L3), eine **Eskalations-E-Mail** von 250–300 Wörtern und **Story Bank Task 5** auf B2.

### Redemittel

- **Protokoll:** *Frau ___ berichtete, dass … · Es wurde in Frage gestellt, ob … · Die Leitung nahm den Einwand zur Kenntnis. · Es wurde die Entscheidung getroffen, … zu … · Der Antrag wurde angenommen. · ___ übernimmt ___ bis zum ___ .*
- **Nominalstil:** *nach Prüfung (+ G) · vor Beginn (+ G) · aufgrund (+ G) · trotz (+ G) · bei Rückfragen · zur Vermeidung (+ G) · im Rahmen (+ G) · im Zuge (+ G)*
- **Kritik:** *Ich würde gern etwas ansprechen. · Mir ist aufgefallen, dass … · Ich sage das nicht als Vorwurf. · Für mich hat das die Folge, dass … · Wie siehst du das? · Können wir festhalten, dass …?*
- **Reagieren:** *Worauf genau beziehen Sie sich? · Dass …, stimmt. Dass …, sehe ich anders. · Das war mein Fehler. · Über den Sachverhalt spreche ich gern, über meine Motive nicht.*
- **Eskalation:** *Wie besprochen halte ich fest: … · Zur Erinnerung an unsere Absprache vom … · Ich würde das gern gemeinsam mit … klären. · Ich sehe mich gezwungen, …* ⬆
