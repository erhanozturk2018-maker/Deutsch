# B2 Recap — Wortschatz

> **Teil 1 von 3** · [Überblick](00_Overview.md) · **Wortschatz** · [Redemittel](02_Redemittel.md) · [Grammatik](03_Grammatik.md)
> **Status: Referenz** — built from the CEFR B2 descriptors; consolidated against the units as they are written (M9).
> **A1–B1 is assumed** ([B1 Wortschatz](../../B1/B1_Recap/01_Wortschatz.md)) and not repeated.

**Was sich an B2-Wortschatz ändert:** at B1 you learned words for topics. At B2 you learn **the difference between near-synonyms**, **the partners a word needs**, and **the register it belongs to**. A B2 word is three pieces of information: the word, its collocations, and where it can be said.

**Legende:** *+ A / + D / + G* = case · ⬆ = gehoben/formal · ⬇ = umgangssprachlich · ≈ = near-synonym with a difference.

## Nomen-Verb-Verbindungen (Funktionsverbgefüge)

The single most B2-sounding thing in German: a noun plus a light verb, where B1 would use one plain verb.

| Verbindung | ≈ einfaches Verb | Beispiel |
|---|---|---|
| eine **Entscheidung treffen** | entscheiden | Der Vorstand hat eine Entscheidung getroffen. |
| **Kritik üben an** (+ D) | kritisieren | Die Zeitung übt Kritik an dem Gesetz. |
| **in Frage stellen** | bezweifeln | Das stellt die ganze Studie in Frage. |
| **zur Verfügung stellen / stehen** | geben / da sein | Die Daten stehen zur Verfügung. |
| **in Kraft treten** | gültig werden | Das Gesetz tritt im Januar in Kraft. |
| **Maßnahmen ergreifen** | handeln | Die Stadt ergreift Maßnahmen. |
| **eine Rolle spielen** | wichtig sein | Der Preis spielt eine große Rolle. |
| **Rücksicht nehmen auf** (+ A) | berücksichtigen | – |
| **Anspruch erheben auf** (+ A) ⬆ | fordern | – |
| **einen Antrag stellen** | beantragen | – |
| **Bezug nehmen auf** (+ A) ⬆ | sich beziehen auf | – |
| **zum Ausdruck bringen** ⬆ | ausdrücken | – |
| **in Betracht ziehen** | erwägen | Wir ziehen beide Optionen in Betracht. |
| **Abstand nehmen von** (+ D) ⬆ | verzichten auf | – |
| **unter Druck setzen / stehen** | drängen / belastet sein | – |
| **Folgen haben für** (+ A) | sich auswirken auf | – |
| **eine Frage stellen / beantworten** | fragen / antworten | – |
| **Wert legen auf** (+ A) | wichtig finden | – |

> These are **not optional decoration**. In formal writing the noun version is the normal one; using only simple verbs is what makes a B2 text read like B1.

## Verben mit Vorsilben: eine Wurzel, sechs Bedeutungen

| Grundverb | Ableitungen |
|---|---|
| **stellen** | **be**stellen (order) · **ver**stellen (adjust; block) · **her**stellen (produce) · **fest**stellen (ascertain) · **vor**stellen (introduce; imagine) · **ein**stellen (employ; adjust; stop) |
| **setzen** | **ein**setzen (deploy; start) · **um**setzen (implement) · **durch**setzen (push through) · **voraus**setzen (presuppose) · **aus**setzen (expose; suspend) · **fort**setzen (continue) |
| **halten** | **ent**halten (contain) · **er**halten (receive; preserve) · **behalten** (keep) · **unter**halten (entertain; maintain) · **verhalten** (sich: behave) · **ein**halten (comply with) |
| **führen** | **ein**führen (introduce) · **durch**führen (carry out) · **aus**führen (execute; export) · **an**führen (cite; lead) · **ver**führen (seduce) · **zurück**führen auf (attribute to) |
| **kommen** | **be**kommen (get) · **an**kommen auf (depend on) · **vor**kommen (occur) · **ent**kommen (escape) · **nach**kommen (+ D: comply) · **zurecht**kommen mit (manage) |
| **nehmen** | **ab**nehmen (decrease; lose weight) · **zu**nehmen (increase) · **an**nehmen (assume; accept) · **auf**nehmen (record; take in) · **teil**nehmen an (participate) · **wahr**nehmen (perceive; take up) |
| **tragen** | **bei**tragen zu (contribute to) · **über**tragen (transfer; broadcast) · **ertragen** (endure) · **vor**tragen (present) · **auf**tragen (apply; commission) |
| **ziehen** | **be**ziehen (obtain; refer) · **ver**ziehen (move away) · **ein**ziehen (move in) · **an**ziehen (attract) · **vor**ziehen (prefer) · **in Betracht ziehen** |

## Nuancen: Wörter, die im Wörterbuch gleich aussehen

| Paar | Unterschied |
|---|---|
| **ändern** ↔ **verändern** | *ändern* = you actively change something (*den Plan ändern*); *verändern* = something becomes different (*Die Stadt hat sich verändert*) |
| **Grund** ↔ **Ursache** | *Grund* = the reason you give; *Ursache* = the objective cause |
| **Folge** ↔ **Auswirkung** | *Folge* = what follows; *Auswirkung* = the effect on something |
| **Möglichkeit** ↔ **Gelegenheit** | *Möglichkeit* = it is possible; *Gelegenheit* = the occasion arose |
| **erfahren** ↔ **erleben** | *erfahren* = to find out; *erleben* = to live through |
| **erkennen** ↔ **anerkennen** | *erkennen* = to recognise (see); *anerkennen* = to acknowledge (accept) |
| **beurteilen** ↔ **verurteilen** | *beurteilen* = to assess; *verurteilen* = to condemn |
| **scheinen** ↔ **erscheinen** | *scheinen* = to seem; *erscheinen* = to appear / be published |
| **bedeuten** ↔ **heißen** | *bedeuten* = to signify; *heißen* = to be called / mean (word) |
| **wirken** ↔ **funktionieren** | *wirken* = to have an effect / come across; *funktionieren* = to work (device) |
| **Gefühl** ↔ **Empfindung** ⬆ | everyday ↔ more refined, often physical |
| **arbeitslos** ↔ **erwerbslos** ⬆ | neutral ↔ administrative register |
| **kriegen** ⬇ ↔ **bekommen** ↔ **erhalten** ⬆ | colloquial ↔ neutral ↔ formal |
| **anfangen** ↔ **beginnen** ↔ **einsetzen** ⬆ | neutral ↔ slightly formal ↔ formal / of processes |
| **sagen** ↔ **äußern** ⬆ ↔ **behaupten** | neutral ↔ formal ↔ claims without proof |

| ⬇ Umgangssprache | Neutral | ⬆ Gehoben / formal |
|---|---|---|
| kriegen | bekommen | erhalten |
| kaputtmachen | zerstören | beschädigen |
| reden über | sprechen über | erörtern |
| Bock haben auf | Lust haben auf | Interesse haben an |
| nicht hinkriegen | nicht schaffen | nicht in der Lage sein zu |
| voll gut | sehr gut | ausgesprochen gelungen |

## Wortbildung auf B2

| Muster | Bedeutung | Beispiele |
|---|---|---|
| **-heit / -keit / -igkeit** | quality | Zuverlässig**keit** · Arbeitslos**igkeit** · Offen**heit** |
| **-ung** | process / result | Umsetz**ung** · Entwickl**ung** · Belast**ung** |
| **-nis** | result / state | Ergeb**nis** · Verständ**nis** · Erkennt**nis** |
| **-tum** | domain | Eigen**tum** · Wachs**tum** |
| **-schaft** | collective | Wissen**schaft** · Gewerk**schaft** · Nachbar**schaft** |
| **-bar / -lich / -sam** | possible / -like / tendency | mach**bar** · verständ**lich** · sparsam |
| **-los / -frei / -arm / -reich** | without / free of / low in / rich in | arbeits**los** · kosten**frei** · fett**arm** · erfolg**reich** |
| **un- / miss- / nicht-** | negation | **un**zuverlässig · **miss**verstehen · **Nicht**raucher |
| **ver- / zer- / ent-** | change / destroy / remove | **ver**ändern · **zer**stören · **ent**lassen |
| **Nominalisierung** | verb → noun | das Entscheiden → **die Entscheidung** · beim **Lesen** |

**Wortfamilie üben:** *entscheiden → die Entscheidung → entscheidend → unentschlossen → die Entschlossenheit → sich entscheiden für*

## Wie viel ist das?

Roughly **4 000–6 000** active items by the end of B2, counting collocations as single items. There is no official CEFR word count; what matters at this level is not the number but that each word comes **with its partners and its register**.

**Sind Sie sicher?** Take any ten items and, for each, say: one collocation, one near-synonym, and whether it is ⬇ / neutral / ⬆. If you can do that, the word is a B2 word for you.
