# C1 Recap — Wortschatz

> **Teil 1 von 3** · [Überblick](00_Overview.md) · **Wortschatz** · [Redemittel](02_Redemittel.md) · [Grammatik](03_Grammatik.md)
> **Status: Referenz** — built from the CEFR C1 descriptors; consolidated against the units as they are written (M10).
> **A1–B2 is assumed** ([B2 Wortschatz](../../B2/B2_Recap/01_Wortschatz.md)) and not repeated.

**Was sich an C1-Wortschatz ändert:** B2 was about having the right word. **C1 is about having the *exact* word** — and knowing what it reveals about you when you use it. Three things come with every C1 item: **Konnotation** (what verdict it carries), **Register** (where it can be said) and **Kollokation** (what it lives with).

**Legende:** ⬆ gehoben/formal · ⬇ umgangssprachlich · ⚖ wertend (carries a judgement) · ≈ near-synonym with a difference.

---

## 1 · Konnotation: dieselbe Sache, ein anderes Urteil

The C1 skill in one table. Each pair describes **the same behaviour** — and takes a different side.

| Positiv / neutral | Negativ ⚖ | Gemeinsame Sache |
|---|---|---|
| sparsam | geizig | spending little |
| selbstbewusst | arrogant · überheblich | sure of oneself |
| entschlossen | stur · starrköpfig | not changing one's mind |
| ehrgeizig | verbissen | wanting to succeed |
| gründlich | pedantisch · kleinlich | paying attention to detail |
| gelassen | gleichgültig · desinteressiert | not getting excited |
| direkt | schroff · taktlos | saying it plainly |
| vorsichtig | ängstlich · zögerlich | not rushing |
| kreativ | chaotisch | not following the plan |
| loyal | unkritisch | standing by someone |
| bescheiden | unterwürfig ⬆ | not claiming much |
| flexibel | beliebig · wankelmütig ⬆ | changing approach |
| preiswert · günstig | billig ⚖ | cheap |
| Politiker | Politikerkaste ⬇⚖ · Funktionär ⚖ | people in politics |
| Maßnahme | Zwangsmaßnahme ⚖ | what a government does |
| Reform | Einschnitt ⚖ · Kürzung ⚖ | a change to a system |

> **Prüftechnik:** when you read an article, ask of every adjective: *would a supporter or an opponent have chosen this word?* That question is C1 reading comprehension.

## 2 · Präzise Unterscheidungen

| Wörter | Unterschied |
|---|---|
| **erfahren ↔ erleben ↔ durchmachen** | find out ↔ live through ↔ endure (hard) |
| **beurteilen ↔ bewerten ↔ verurteilen** | assess ↔ grade/evaluate ↔ condemn |
| **feststellen ↔ behaupten ↔ vermuten** | establish (as fact) ↔ claim ↔ suspect |
| **erklären ↔ begründen ↔ rechtfertigen** | explain ↔ give reasons for ↔ justify (defensively) |
| **verändern ↔ verwandeln ↔ umgestalten** | change ↔ transform ↔ redesign |
| **fördern ↔ unterstützen ↔ begünstigen ⚖** | promote ↔ support ↔ favour (unfairly) |
| **vermeiden ↔ verhindern ↔ unterbinden ⬆** | avoid ↔ prevent ↔ suppress |
| **Anspruch ↔ Forderung ↔ Zumutung ⚖** | claim ↔ demand ↔ unreasonable demand |
| **Ergebnis ↔ Erkenntnis ↔ Folge** | result ↔ insight ↔ consequence |
| **Voraussetzung ↔ Bedingung ↔ Vorbehalt** | prerequisite ↔ condition ↔ reservation |
| **Zweifel ↔ Bedenken ↔ Einwand** | doubt ↔ misgivings ↔ objection (stated) |
| **Absicht ↔ Vorhaben ↔ Bestreben ⬆** | intention ↔ plan ↔ endeavour |
| **Auffassung ↔ Ansicht ↔ Haltung** | view (reasoned) ↔ opinion ↔ stance (lasting) |
| **Sachverhalt ↔ Tatsache ↔ Umstand** | state of affairs ↔ fact ↔ circumstance |
| **wesentlich ↔ erheblich ↔ maßgeblich ⬆** | essential ↔ considerable ↔ decisive |
| **vermeintlich ↔ angeblich ↔ scheinbar ↔ anscheinend** | supposed (wrongly) ↔ allegedly ↔ seemingly (but not) ↔ apparently (probably) |

> ***scheinbar* vs *anscheinend*** is a genuine native-speaker shibboleth: *scheinbar* = it looks that way **but isn't**; *anscheinend* = it looks that way **and probably is**.

## 5 · Redewendungen und feste Bilder

Idioms are C1 **when you know their register**. All of the following are usable in serious writing or speech unless marked ⬇.

| Wendung | Bedeutung |
|---|---|
| **den Rahmen sprengen** | to go beyond what is possible here |
| **ins Gewicht fallen** | to matter, to count |
| **zur Sprache bringen** ⬆ | to raise (a topic) |
| **außer Frage stehen** | to be beyond doubt |
| **in Kauf nehmen** | to accept (a downside) |
| **auf der Hand liegen** | to be obvious |
| **zu kurz greifen** | to be too simple an explanation |
| **den Ausschlag geben** | to be the deciding factor |
| **ins Auge fallen** | to be striking |
| **eine Rolle spielen ↔ keine Rolle spielen** | to matter ↔ not to matter |
| **die Weichen stellen für** | to set the course for |
| **an seine Grenzen stoßen** | to reach its limits |
| **unter die Lupe nehmen** | to examine closely |
| **Hand in Hand gehen mit** | to go together with |
| **auf dem Spiel stehen** | to be at stake |
| **zu Buche schlagen** ⬆ | to make a financial difference |
| **den Finger in die Wunde legen** ⚖ | to name the painful point |
| **das ist an den Haaren herbeigezogen** ⚖ | that is far-fetched |
| **etwas auf die lange Bank schieben** ⬇ | to keep postponing |
| **mit zweierlei Maß messen** ⚖ | to apply double standards |

> **Warnung:** an idiom in the wrong register is worse than a plain sentence. In an academic text, *den Rahmen sprengen* is fine; *auf die lange Bank schieben* is not.

## 9 · Wortbildung, produktiv genutzt

| Muster | Bedeutung | Beispiele |
|---|---|---|
| **-ierung / -ation** | process (often from a foreign verb) | Digital**isierung** · Organis**ation** · Modern**isierung** |
| **-ismus / -ist / -istisch** | doctrine / adherent / adjectival | Kapital**ismus** · Ideal**ist** · real**istisch** |
| **-wesen** | the whole system of | Bildungs**wesen** · Gesundheits**wesen** |
| **-bereich / -sektor** | field | Dienstleistungs**bereich** |
| **-grad / -maß / -quote** | degree / measure / rate | Beschäftigungs**quote** · Schwierigkeits**grad** |
| **-fähig / -würdig / -pflichtig** | able to / worth / obliged to | zahlungs**fähig** · förder**würdig** · melde**pflichtig** |
| **-frei / -los / -arm / -intensiv** | free of / without / low in / intensive | kosten**frei** · arbeits**intensiv** |
| **Präfixe der Verstärkung** | – | **hoch**qualifiziert · **über**bewertet · **unter**schätzt · **miss**verständlich |
| **un- vs nicht-** | opposite vs plain negation | **un**zulässig (forbidden) vs **nicht**staatlich (non-state) |
| **Fugen-s** | linking element in compounds | Arbeit**s**markt · Regierung**s**erklärung · Verwaltung**s**akt |

> **Komposita lesen:** read the last element first — *die Regierungserklärung* = *eine Erklärung* ← *der Regierung*. A four-part compound is normal and is not a vocabulary item you need to have seen.

## Wie viel ist das?

Roughly **8 000–12 000** items of receptive vocabulary and a large active core. There is no official CEFR count, and at C1 the number stops being useful: what counts is **precision, connotation and range of register**.

**Sind Sie sicher?** Take any paragraph you wrote and for five words ask: *Is there a more exact one? A more formal one? A more colloquial one? Does mine carry a judgement I did not intend?* If you can answer all four, you are working at C1.
